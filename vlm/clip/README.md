# CLIP / Vision-Language Model Study

This folder contains my study of the basic structure of CLIP and Vision-Language Models.

## Contents

### clip_step_by_step.ipynb
- Image and text feature extraction
- Projection into a shared embedding space
- L2 normalization
- Image-text similarity matrix
- Contrastive loss

### clip_model_implementation.ipynb
- Simple CLIP module using pretrained ViT and BERT encoders
- Image/Text projection layers
- Contrastive learning
- Freezing pretrained encoders

### clip_pretrained_usage.ipynb
- Pretrained CLIP inference
- Image-text similarity
- Zero-shot classification
